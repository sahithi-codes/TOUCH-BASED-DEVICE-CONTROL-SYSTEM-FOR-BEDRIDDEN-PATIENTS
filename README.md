This project presents a secure, touch-activated assistive control framework designed to empower bedridden and mobility-impaired individuals using the LPC2148 ARM7 microcontroller. The system features a resistive touchscreen interface secured by password authentication to prevent unintended or accidental device actuation. User credentials are dynamically managed and safely stored in non-volatile EEPROM. Connected home devices (simulated via status LEDs) can be independently operated upon successful login, while an integrated high-priority acoustic alarm (buzzer) ensures rapid caregiver notification during emergencies.
